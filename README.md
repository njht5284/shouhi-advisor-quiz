# 消費生活アドバイザー試験対策

消費生活アドバイザー資格試験（消費生活相談員資格試験兼用）第1次試験の過去問（12回分・1,800小問）をスマートフォンで反復学習できるオフライン対応PWAです。

## 使い方（ホーム画面への追加）

このアプリはHTTPS（またはlocalhost）で配信されたページ上でのみオフライン機能（Service Worker）が有効になります。LANの `http://` アドレスではオフライン動作・ホーム画面インストールが機能しません。

### iOS Safari
1. Safariでアプリのページを開く
2. 下部（または上部）の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選択

### Android Chrome
1. Chromeでアプリのページを開く
2. 右上のメニュー（⋮）をタップ
3. 「ホーム画面に追加」または「インストール」を選択

一度ホーム画面に追加すれば、以降はネットワーク接続なしで全機能が利用できます。

## 収録内容・出題モード

- 過去12回（2023〜2025年度）・全1,800小問
- 本番モード／ランダムモード／分野別モード／復習モードの4モード
- 回答直後に正誤・正答・解説を表示
- 分野別の正答率統計、直近の学習履歴

## データ・注意事項

- 学習データ（回答結果・履歴）はすべて端末内（IndexedDB）に保存されます。外部送信は一切行いません。
- 解説は学習用の要約です。法令の正確な適用や最新の改正状況については、必ず原典（法令・公式資料）でご確認ください。
- 一部の分野（繊維学、建材科学の一部など）は提供講義資料に該当箇所が見当たらず「要補完」として扱っています。該当する解説には一般知識に基づく参考情報である旨を付記しています。

## 開発者向け情報

### ディレクトリ構成

```
shouhi-advisor-quiz/
  index.html / style.css / app.js 他JS       # PWA本体
  manifest.json / sw.js / icon*.svg          # PWA設定
  data/questions.json / data/categories.json # 学習データ（Step 0の成果物）
  extract/                                    # データ抽出パイプライン（Python）
```

### データセットの再生成

過去問PDF・正答解説Excelから `data/questions.json` を再生成する場合:

```bash
cd extract
python build_dataset.py --exam 2023-10-14   # パイロット: 1試験分のみ
python build_dataset.py --all                # 本番: 全12試験分
```

`extract/validation_report.txt` に正答の突き合わせ警告が出力されます。`[参考]` 接頭辞の警告は「マーカー（①②③④・〇×）は一致するが本文の表記が異なる」（Excel側の補足追記等）という参考情報で、正答の判定自体には影響しません。

### ローカルでの動作確認

```bash
python -m http.server 8420 --directory shouhi-advisor-quiz
```

`http://localhost:8420` を開くとService Workerも有効な状態で確認できます（localhostはHTTPS扱い）。

### 出荷時の注意

ファイルを更新して再配信する際は `sw.js` の `CACHE_NAME`（例: `shouhi-quiz-v2`）を上げてください。上げないと利用者の端末で古いキャッシュが使われ続けます。
