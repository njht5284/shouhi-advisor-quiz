# ファクトチェックレポート：完全一致する重複問題の検出

対象: `data/questions.json`（消費生活アドバイザー試験対策アプリの学習データ、全12回・1,800小問）
検証日: 2026-08-24

## 総合サマリー

検証件数: 1,800件
**完全一致する重複問題: 0件**

除外は行っていません（除外すべき対象が見つからなかったため）。

## 検証方法

1,800件の小問全件について、内容が完全一致するものがないかを機械的に突合しました。

- **正誤判定型（true_false）**: 判定対象の文章（`prompt`）そのものをキーに突合。同じ文章が2回以上出現するかを確認。
- **穴埋め型（fill_blank）**: 選択肢の元になる本文（`passage`）＋選択肢の組み合わせをキーに突合。（`prompt`は「【ア】の部分に最も適当なものを、下記の選択肢から選びなさい。」のような定型文が全問共通のため、キーとして使えません。）

## 調査の過程で見つかった誤検知とその原因

1回目の突合では17グループ・39件が「重複候補」として検出されましたが、詳細を確認したところ、これらは**すべて誤検知**でした。

原因は、同じ大問（例: 問6）内で、【ア】【イ】【ウ】【エ】のような複数の空欄が**共通の選択肢セット**を使い回しているためです。これは出題側が意図した正当な形式（1つの語群から複数の空欄にそれぞれ異なる語を当てはめさせる）であり、重複ではありません。証拠として、これら17グループは全件で「正答が互いに食い違って」いました（同じ選択肢セットに対し、空欄ごとに異なる正答が設定されている）。

例:
```
問6-1（【ア】）: 選択肢 ①基本理念 ②目的 ③定義 ④定款 → 正答 ②目的
問6-4（【エ】）: 選択肢 ①基本理念 ②目的 ③定義 ④定款 → 正答 ①基本理念
```
同じ選択肢セットですが、別々の空欄・別々の正答であり、別の設問です。

この誤検知を除去するため、**同じ大問（同一試験・同一問番号）内での一致は比較対象から除外**し、異なる大問（異なる試験、または同じ試験内の異なる問番号）にまたがって内容が完全一致するケースのみを「真の重複候補」として再判定しました。その結果、該当は0件でした。

## 論理的整合性の指摘事項

特に問題は見つかりませんでした。1,800件は12回の異なる試験実施回から独立して収集された過去問であり、選択肢の語群使い回し（同一大問内）を除けば、内容が完全一致する設問は存在しません。

## 検証対象外の記述

今回は「完全一致」を基準とした機械的な突合のみを行いました。表現を変えた類似問題（同じ論点を異なる言い回しで問うもの）の検出は依頼の範囲外のため対象外としています。ご希望があれば別途対応します。
